# 阶段五：测试数据与联调说明

## 1. 目标

本文档用于固定阶段五的联调测试环境准备方式，确保搜索、分支树、祖先查询和亲缘路径模块都基于同一组稳定数据完成验证与演示。

## 2. 当前阶段约定

- 所有已登录用户默认可读取族谱与阶段五查询结果。
- `search/members` 返回分页搜索结果并附带重名辅助字段。
- `search/branch-tree` 返回后代子图的层级节点列表。
- `kinship/ancestors/{member_id}` 返回祖先子图的层级节点列表。
- `kinship/path` 返回最短路径的 `nodes + edges` 结果。
- 亲缘路径默认排除 `ended` 婚姻；显式开启参数后才纳入。

## 6. 建议验证顺序

### 6.1 后端与前端基础验证

执行：

```bash
pytest backend/tests -q
python -m compileall backend/app backend/tests scripts/dev
cd frontend && npm run build
```

### 6.2 数据准备验证

- `stage3_creator` 登录后应能看到 `Stage3 Managed Tree` 的四个查询入口
- `Stage5 Merge Child`、`Stage5 Great Great Grandchild` 应可在成员搜索中搜到
- `Stage5 Duplicate Ming` 应至少返回两条结果
- `Stage4 Ended Husband` 应已成为主谱系可达节点

### 6.3 手工联调验证

- 在 `Stage3 Managed Tree` 的“成员搜索”页搜索 `Duplicate Ming`
- 在“分支树预览”页输入 `Stage4 Root Patriarch` 的成员 ID
- 在“祖先查询”页输入 `Stage5 Great Great Grandchild` 的成员 ID
- 在“亲缘路径”页输入 `Stage4 Root Patriarch` 与 `Stage4 Ended Wife` 的成员 ID
- 先不勾选 `ended` 婚姻，再勾选一次，对比结果差异
- 在成员详情页进入 `Stage5 Merge Child`，通过快捷入口跳到祖先页、分支树页和亲缘页

## 7. 手工验收关注点

- 查询页是否都能从族谱详情页进入
- 成员详情页的三个快捷查询入口是否可用
- 搜索结果是否能用父母姓名区分两个 `Stage5 Duplicate Ming`
- `Stage4 Root Patriarch` 的分支树中是否能看到长链后代节点
- `Stage5 Great Great Grandchild` 的祖先链是否至少展开 4 代
- `Stage5 Merge Child` 是否在某些根查询下通过多条路径出现
- `Stage4 Root Patriarch` 到 `Stage4 Ended Wife` 的路径是否仅在开启 `ended` 婚姻后出现
