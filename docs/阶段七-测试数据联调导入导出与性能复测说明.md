# 阶段七：测试数据、联调、导入导出与性能复测说明

## 1. 目标

本文档用于固定阶段七全量规则生成数据的准备方式、导入导出流程和性能复测口径，确保阶段七结果可重复、可展示、可写入实验报告。

## 2. 当前阶段约定

- 阶段七数据是性能基准数据，不替换阶段四至六的小规模联调数据
- 所有成员均为规则生成
- 不使用真实历史人物
- `COPY` 为唯一正式导入方案
- 性能对比固定围绕姓名模糊查询与四代查询

## 2.1 默认联调账号

- `stage7_importer`：10 棵族谱的创建者
- `stage7_collaborator`：10 棵族谱的协作者
- `stage7_reader`：10 棵族谱的只读用户

## 4. 执行顺序

### 4.1 生成树配置索引

```bash
python scripts/stage7/build_seed_manifests.py
```

### 4.2 生成大规模 CSV

```bash
python scripts/stage7/generate_dataset.py
```

### 4.3 导入数据库

```bash
export DATABASE_URL='postgresql://...'
python scripts/stage7/import_copy.py
```

如果数据库已经导入过旧版阶段七数据，只需要修正联调账号和协作者授权，可执行：

```bash
psql "$DATABASE_URL" -f scripts/stage7/patch_stage7_accounts.sql
```

### 4.4 导出指定分支

```bash
export DATABASE_URL='postgresql://...'
python scripts/stage7/export_branch.py --tree-id 7003 --root-member-id 1018001
```

### 4.5 运行性能对比

```bash
export DATABASE_URL='postgresql://...'
python scripts/stage7/benchmark_explain.py --tree-id 7003 --keyword 朱德 --ancestor-member-id 1018001
```

## 5. 建议验证口径

### 5.1 数据规模

- `family_tree.csv` 至少 10 行
- `member.csv` 至少 105000 行
- 至少 1 棵树拥有 55000 以上成员

### 5.2 数据质量

- 所有成员都有 `birth_date`
- `is_alive = false` 的成员都带 `death_date`
- 活人年龄不超过 110
- 90 岁以上活人数量很少

### 5.3 导入后计数

- `family_tree`、`member`、`parent_child`、`marriage` 行数与 CSV 一致
- `member_provenance.csv` 行数应与 `member.csv` 一致

### 5.4 导出闭包

- 导出 `member.csv` 中包含所有关系两端成员
- 导出 `parent_child.csv` 与 `marriage.csv` 不引用闭包外成员

### 5.5 性能验证

- `idx_member_name_trgm` 前后都有执行计划
- `idx_parent_child_tree_parent` 前后都有执行计划
