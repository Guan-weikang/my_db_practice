# 阶段七：数据来源与真实性边界说明

## 1. 文档目的

本文档用于固定阶段七的数据策略、真实性边界和生成约束，避免将课程性能数据误认为真实历史族谱数据。

## 2. 当前策略

阶段七现统一采用“全量规则生成”方案：

- 不使用真实历史人物
- 不使用互联网公开族谱中的真实人物姓名、父子关系和生卒年
- 族谱名称可保留为展示主题，例如“汉朝刘氏”“唐朝李氏”“明朝朱氏”“吴越钱氏”“孔氏”
- 但这些树中的具体成员全部按统一规则生成

## 3. 为什么放弃真实历史人物

在实际验证中发现：

- 大量历史人物缺少稳定、完整、可落库的生卒年
- 真实历史人物信息残缺会导致 `is_alive`、`death_date`、寿命统计与阶段六统计结果失真
- 若继续混用真实人物与生成成员，会让阶段七的性能数据与课程演示口径变得模糊

因此阶段七正式收口为：

- 只保留“族谱主题名”
- 所有成员均为规则生成
- 数据目标优先服务于规模、导入导出和性能实验

## 4. 规则生成边界

- 所有成员必须有 `birth_date`
- 已死亡成员必须有 `death_date`
- `is_alive = true` 的成员在 2026 年年龄不得大于 110
- 90 岁以上仍存活成员必须保持极低比例
- 高辈分成员应当大部分已经死亡
- 不生成跨树关系
- 不生成父母自环
- 每个成员最多 1 父 1 母
- 婚姻主键始终满足 `member_id_1 < member_id_2`

## 5. 当前数据来源

阶段七当前不依赖外部互联网数据源。

当前实际来源只有：

- 内置树配置
- 内置姓名词表
- 内置代际生成规则
- 内置寿命与存活概率规则

## 6. 当前不做的事情

- 不采集真实历史人物
- 不抓取家谱网站
- 不做扫描版家谱 OCR
- 不混用真实人物和生成人物
- 不为阶段七维护任何真实人物 seed manifest
