# 阶段七：数据来源与真实性边界说明

## 1. 文档目的

本文档用于固定阶段七的数据来源白名单、真实性边界和可复用策略，避免在“课程性能数据”和“历史真实谱系”之间混淆目标。

## 2. 核心原则

- 阶段七的首要目标是满足课程要求中的规模、导入导出与性能验证。
- 互联网中的真实族谱数据只用于构建少量“真实种子谱系”。
- 除真实种子层外，其余大部分成员均为生成数据，不伪装成真实历史人物。
- 不做无授权整站抓取，不做扫描家谱 OCR 批量入库，不做大模型臆造真实人物关系。

## 3. 数据来源分级

### 3.1 Tier A：可程序化利用的优先来源

- `Wikidata`
  - 作用：抽取知名人物的姓名、父子、婚配、出生卒年等结构化骨架
  - 用途：作为阶段七真实种子层的首选来源
  - 许可参考：<https://www.wikidata.org/wiki/Wikidata:Licensing>

- `CBDB API / China Biographical Database`
  - 作用：补强中国历史人物、家族与官宦关系
  - 用途：作为唐李、孔氏及其他士族分支的结构化补充来源
  - 入口参考：<https://input.cbdb.fas.harvard.edu/cbdbapi/index.html>

### 3.2 Tier B：只做人工校验参考，不做批量导入

- `FamilySearch Chinese Genealogy`
  - 作用：核对家族存在性、谱系展示方式和家谱资源线索
  - 入口参考：<https://www.familysearch.org/en/chinese>

- `上海图书馆家谱检索`
  - 作用：核对家谱馆藏、支派名称、目录线索
  - 入口参考：<https://search.library.sh.cn/jiapu>

- 其他公开家谱平台、数字馆藏和官方媒体资料
  - 作用：作为字辈、支派、谱系样式的人工确认来源
  - 当前阶段不作为自动抽取主源

## 4. 真实信息保留边界

- 真实种子层固定只保留少量高知名度人物
- 真实种子成员允许保留：
  - 真实姓名
  - 已知或可稳定核验的出生卒年
  - 已知父子关系
  - 已知婚配关系
  - 来源系统、来源 URL 和置信度
- 对于 BCE 年份、模糊年份或现有表结构不便直接落库的信息：
  - 在 seed manifest 与 provenance 文件中保留
  - 生成数据库 CSV 时可留空 `birth_date` / `death_date`

## 5. 当前固定的真实种子树

阶段七固定纳入以下 5 棵真实种子树：

1. 汉朝刘氏
2. 唐朝李氏
3. 明朝朱氏
4. 吴越钱氏
5. 孔氏

当前仓库中的初始 seed manifest 位于：

- [data/stage7/seeds](/home/mochen/db_practice/data/stage7/seeds)

这些 manifest 采用 curated 方式先落第一版，可在后续迭代中逐步替换为更正式的自动抽取流程。

## 6. 当前不做的事情

- 不直接从扫描版家谱识别 10 万级人物
- 不把公开馆藏目录当作可直接导入的结构化数据
- 不承诺完整复刻汉刘、唐李、明朱、吴越钱、孔氏的真实全谱
- 不把生成扩展节点标记成真实历史人物

## 7. 实施约束

- 种子层与生成层必须可区分
- 生成层必须保留 sidecar provenance
- 生成器不得改写真实种子层的姓名、父子关系和婚配关系
- 阶段七性能实验应使用“真实种子 + 合成扩展”的混合数据，而不是只靠人工整理的真实人物数据
