# 阶段六：测试数据与联调说明

## 1. 目标

本文档用于固定阶段六的联调测试环境准备方式，确保 Dashboard 与三类统计分析接口都基于同一组稳定数据完成验证与演示。

## 2. 当前阶段约定

- 所有已登录用户默认可读取族谱与阶段六统计结果。
- `analytics/dashboard` 返回单个族谱的总人数、男女数量、未知性别数量与男女比例。
- `analytics/generation/max-average-lifespan` 返回平均寿命最长的一代，空结果时返回 `item = null`。
- `analytics/members/older-than-50-unmarried-male` 返回超过 50 岁且没有配偶的男性成员列表。
- `analytics/members/before-generation-average-birth-year` 返回出生年份早于本代平均出生年份的成员列表。
- Dashboard 页面基于当前用户可访问的族谱列表进行切换，不做全局跨族谱统计。

## 5. 默认种子数据拓扑

### 5.1 复用的阶段五基线

继续复用：

- `Stage3 Managed Tree`
- `Stage3 Public Read Tree`
- 阶段五的查询主链、重名样例、ended 婚姻样例与公共可读树样例

这些样例继续用于阶段五查询能力回归和阶段六权限基线复核。

### 5.2 阶段六新增空树样例

新增族谱：

- `Stage6 Empty Analytics Tree`

用途：

- 验证 Dashboard 汇总统计空树时返回 0 人数和 `null` 比率
- 验证三类课程统计空结果结构稳定

### 5.3 阶段六新增 unknown 性别样例

新增族谱：

- `Stage6 Unknown Analytics Tree`

新增成员：

- `Stage6 Unknown Gender Sample A`
- `Stage6 Unknown Gender Sample B`

用途：

- 验证只有 `unknown` 性别成员时 Dashboard 男女比率为空
- 验证 `unknown` 计入总人数但不进入男女比率分子

### 5.4 阶段六新增统计主样例

新增族谱：

- `Stage6 Analytics Study Tree`

新增成员：

- `Stage6 Gen1 Long Life A`
- `Stage6 Gen1 Long Life B`
- `Stage6 Gen2 Shorter Life`
- `Stage6 Eligible Elder`
- `Stage6 Ended Marriage Elder`
- `Stage6 Ended Marriage Spouse`
- `Stage6 Early Gen3`
- `Stage6 Mid Gen3`
- `Stage6 Late Gen3`
- `Stage6 Missing Birth Sample`

新增关系说明：

- `Stage6 Ended Marriage Elder` 与 `Stage6 Ended Marriage Spouse` 保持一条 `ended` 婚姻

用途：

- 验证平均寿命最长的一代稳定命中 `generation_no = 1`
- 验证超过 50 岁且无配偶男性列表只返回 `Stage6 Eligible Elder`
- 验证存在 `ended` 婚姻的男性成员不会落入“没有配偶”结果
- 验证 `Stage6 Early Gen3` 命中“早于本代平均出生年份”统计
- 验证缺少 `birth_date` 的成员不会污染寿命与出生年份统计

## 6. 建议验证顺序

### 6.1 后端与前端基础验证

执行：

```bash
pytest backend/tests -q
python -m compileall backend/app backend/tests scripts/dev
cd frontend && npm run build
```

### 6.2 数据准备验证

- `stage3_creator` 登录后应能进入 Dashboard 页面
- Dashboard 下拉框中应至少能看到：
  - `Stage6 Empty Analytics Tree`
  - `Stage6 Unknown Analytics Tree`
  - `Stage6 Analytics Study Tree`
- `Stage6 Analytics Study Tree` 中应存在 `Stage6 Eligible Elder`
- `Stage6 Ended Marriage Elder` 与 `Stage6 Ended Marriage Spouse` 应已形成 `ended` 婚姻

### 6.3 手工联调验证

- 在 Dashboard 中切换到 `Stage6 Empty Analytics Tree`
- 在 Dashboard 中切换到 `Stage6 Unknown Analytics Tree`
- 在 Dashboard 中切换到 `Stage6 Analytics Study Tree`
- 对比三棵树下四个统计区块的展示差异
- 验证 URL 中 `?treeId=` 与页面当前选择保持一致

## 7. 手工验收关注点

- 空树是否返回 0 总人数与空比例，而不是报错
- only-unknown 树是否显示总人数但不显示男女比例
- `Stage6 Analytics Study Tree` 的“平均寿命最长一代”是否返回第 1 代
- “超过 50 岁且没有配偶的男性成员”是否只返回 `Stage6 Eligible Elder`
- `Stage6 Ended Marriage Elder` 是否不会出现在无配偶统计列表中
- “出生年份早于本代平均出生年份的成员”是否包含 `Stage6 Early Gen3`
- Dashboard 四个区块是否分别具备 loading、error、empty、success 展示能力
