# Stage7 Generated CSV Output

本目录用于存放阶段七生成器产出的 CSV 文件。

默认生成命令：

```bash
python scripts/stage7/generate_dataset.py
```

默认输出文件包括：

- `user_account.csv`
- `family_tree.csv`
- `tree_collaborator.csv`
- `member.csv`
- `parent_child.csv`
- `marriage.csv`
- `member_provenance.csv`

这些 CSV 属于可重复生成产物，不需要手工维护。
